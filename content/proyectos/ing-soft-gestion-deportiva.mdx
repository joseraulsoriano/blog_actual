Academic Software Engineering project. Multi-role system (admin, teacher, student) for sports management. Student module: edit profile, monthly payments, view recommendations. Recommendations locked if in arrears.

> Student panel and management flows

### Destacados

- **Login and roles** — Email/password auth and redirect by role.
- **Payment and Recommendation classes** — JS OOP: Payment (month, amount, status), Recommendation (date, text).
- **Payment management** — Payment history, payment form, block recommendations if overdue.

### Stack

`HTML5` · `CSS3` · `JavaScript` · `fetch` · `localStorage` · `JSON`
