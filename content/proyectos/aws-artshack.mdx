Site for a coffee and crafts business: hero, menu, products (ceramics, tote bags), table reservations, and About. Planned AWS architecture (Amplify, GraphQL, Cognito) for dynamic catalog and auth. Full Next.js frontend with Tailwind and routes: /menu, /productos, /reservas, /nosotros, /dashboard.

> Coffee, art, and experiences in one place

### Destacados

- **Landing and specialties** — Hero, craft coffee, ceramics, tote bags. Links to menu and products.
- **Reservations and menu** — Table booking, coffee menu, and handmade products.
- **Planned AWS integration** — GraphQL in deps; Cognito/Amplify auth and API as next steps.

### Stack

`Next.js 14` · `React` · `Tailwind CSS` · `GraphQL` · `TypeScript`
