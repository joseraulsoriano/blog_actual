En `angular/crud_escolar_api/` conviven la API REST (Django / Django REST Framework) y el front Angular: formularios reactivos, validación, tablas con paginación y manejo de errores HTTP. Un solo clon del monorepo sirve para levantar backend y cliente contra el mismo contrato documentado en el README.

> angular/crud_escolar_api (Django REST + SPA Angular)

### Destacados

- **REST** — HttpClient, interceptores opcionales y modelos alineados al API.
- **Formularios** — Reactive forms, validación y mensajes de error de API.
- **Listados** — Tablas con carga, filtros y estados vacío / error.

### Stack

`Angular` · `TypeScript` · `REST` · `SCSS`
