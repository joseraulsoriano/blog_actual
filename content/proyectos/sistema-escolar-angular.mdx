Full-stack academic system: Django REST with JWT, Angular 16 with student, teacher, admin, events, and charts modules. Stateless REST API and SPA with domain services. Código de la webapp en el monorepo `angular-repo` (`angular/sistema-escolar-webapp/`).

> School CRUD with roles, events, and charts

### Destacados

- **Auth and roles** — JWT login, cookies, redirect by role (admin, teacher, student).
- **Academic management** — CRUD students/teachers, user signup, academic events.
- **Charts and stats** — Chart.js via ng2-charts.

### Stack

`Angular 16` · `Django REST Framework` · `MySQL` · `TypeScript` · `SCSS` · `Bootstrap` · `ng2-charts` · `ngx-cookie-service`
