Two-part repo: recetario-mcp (Python/FastAPI) and backend-alexa (Node.js). Flow: Alexa Lambda → backend-alexa → recetario-mcp → Brave/scraping. Backend exposes /api/mcp/recipes, ingredients, etc.

> Voice to recipes: Alexa calls backend, backend calls MCP

### Destacados

- **MCP + Alexa backend** — recetario-mcp on port 8012, backend-alexa on 3001.
- **Render deployment** — Two web services: one for MCP, one for backend.
- **Environment variables** — BRAVE_API_KEY, MCP_BASE_URL to link services.

### Stack

`Python` · `FastAPI` · `Node.js` · `Alexa` · `Lambda` · `Brave Search` · `Docker`
