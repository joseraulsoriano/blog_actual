Repositorio smart-route-tiendas-3b: workspace pnpm con apps web, móvil y API Python, paquetes `types`, `api-client`, `utils` y UI web/native. Documentación de setup, Docker Compose y desarrollo paralelo con `pnpm dev`.

> Monorepo full-stack para retail

### Destacados

- **Rutas y optimización** — Enfoque en recorridos eficientes alineado al caso de uso de tiendas 3B.
- **Tres superficies** — Web, Expo y API coordinadas desde un solo repositorio.
- **Dev experience** — Turborepo, filtros pnpm y entorno reproducible (Node 18+, Python 3.11+).

### Stack

`TypeScript` · `React` · `Vite` · `Expo` · `FastAPI` · `Turborepo` · `pnpm` · `Docker`
